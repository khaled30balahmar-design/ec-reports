عند فتح الطالب لهذا الرابط، ستفتح له صفحة التسجيل الاحترافية فقط وتُحفظ إجابته مباشرة في Google Sheets.

كود Google Apps Script الموحد (انسخه في الشيت)

1. من داخل ملف Google Sheet اختر Extensions > Apps Script والصق هذا الكود مكان أي كود سابق ثم اضغط حفظ 💾.

2. اضغط Deploy > Manage deployments > تعديل ✏️ > New version وتأكد أن Who has access = Anyone.

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var body = {};
    if (e.postData && e.postData.contents) {
      try { body = JSON.parse(e.postData.contents); } catch(err) {}
    }
    var params = e.parameter || {};
    var answers = body.answers || body.customAnswers || body;

    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["التاريخ والوقت", "عنوان النموذج", "الاسم الثلاثي", "رقم الجوال", "البريد الإلكتروني", "الرقم الجامعي", "جميع الإجابات"]);
    }

    var row = [
      new Date().toLocaleString("ar-SA", { timeZone: "Asia/Riyadh" }),
      body.formTitle || params.formTitle || "نموذج نادي الاقتصاد",
      body.fullName || answers["الاسم الثلاثي"] || params.fullName || "",
      "'" + (body.phone || answers["رقم الجوال"] || params.phone || ""),
      body.email || answers["البريد الإلكتروني"] || params.email || "",
      body.studentId || answers["الرقم الجامعي"] || params.studentId || "",
      JSON.stringify(answers)
    ];
    sheet.appendRow(row);
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
